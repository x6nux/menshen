# 面板、命令与通知

## 管理面板

私聊 bot 发 `/start` 就是管理面板。主菜单按角色决定露出哪些入口：

- **🤖 我的机器人** —— 接入新 bot、管理生效群、逐群配置阈值与行为
- **👥 管理员**（主管理员）—— 添加次级管理员，配额 `max_bots_per_admin`
- **🚫 联合封禁**（主管理员）—— 全平台封禁开关与名单
- **🔌 上游渠道**（主管理员）—— AI 上游列表（base_url + api_key）
- **🤖 模型定价**（主管理员）—— 按 `上游名/模型ID` 录入模型与单价，用于把开销折算成钱；判定 / 复判模型在「全局设置」里按重试顺序填列表
- **⚙️ 全局设置**（主管理员）—— 默认判定模型、总开关、私聊汇总间隔等

「🙈 豁免用户」页同时列出解禁码 / `/white` 产生的**白名单**行（范围、来源、
到期时间），可逐条移除。

面板上的请求都走按钮，由 bot 私聊完成，不需要额外的 Web 后台。

**接入一个 bot**：面板上点「➕ 接入新机器人」，把 BotFather 给的 token 发过来
就行。本服务会自动验证它、取回 bot 的身份、起实例并注册回调地址，全过程
在一条消息里实时汇报。你发的那条含 token 的消息**会被自动删掉** —— token
等同于该 bot 的完整控制权，不该留在聊天记录里。

配置文件里那个 bot 是**主 bot**：只做配置管理 + 接入其他 bot，不入群、
不判定广告，被拉进群或频道会自动退出。它的详情页是只读的，也不能停用或
移除。群里干活的是面板上接入的**工作 bot**。

## 多租户

主管理员掌握上游、模型与联合封禁 —— 也就是掌握钱。他可以添加**次级
管理员**，次管各自接入自己的 bot、管自己那些 bot 在各群的行为与判定阈值。

| | 主管理员 | 次级管理员 |
|---|---|---|
| 上游渠道 / 模型定价 | ✅ | ❌ |
| 判定模型 | 全局默认 + 为单个 bot 覆盖 | ❌ 由主管配 |
| 接入 bot | 全部 | 只限自己名下（配额 `max_bots_per_admin`） |
| 群配置 / 阈值 / 流水 | 全部 | 只限自己 bot 名下 |
| 联合封禁开关与名单 | ✅ | ❌ |

主管理员名单只存在于配置文件里，不进数据库 —— 面板上删不掉它。

## 群内命令

全部支持回复对方消息发，或直接带 `<user_id>` 参数。群里 TG 客户端会自动补
`@botname`，两种形态都认得。

| 命令 | 作用 | 权限 |
|---|---|---|
| `/check` | 复查某人是否在发广告：把该用户在本群的**全部留底**一次性交给两个模型，两方结论互相印证后走同一套处置矩阵 | 所有人 |
| `/ban` | **人工直接标记为广告**：不经过 AI，按最高档处置（删除 + 禁言）并进联合封禁名单 | 群管理员及以上 |
| `/white` | 加入本群反广告白名单（频道填 `-100` 开头的 ID）；**私聊里是加入本 bot 的豁免名单** | 群管理员及以上 / 管理员私聊 |
| `/log <id>` | 记录卡片：判定、处置、原文查看入口，卡片上可直接处置 | 管理员私聊 |
| `/user <uid>` | 此人的判定记录列表（每页 10 条），每条可点开处置 | 管理员私聊 |

`/check` 对所有人开放：它不直接封禁，而群成员往往比管理员更早发现广告。
它同时是花钱与骚扰入口，靠 `antiad_cmd_rpm` 按发起人限频。

`/ban` 与 `/white` 限群管理员及以上（群管 / bot 归属人 / 主管理员）。
`/ban` 绕过判定直接删人禁言，对全群开放等于把删消息的权力交给任何人。
非授权者**静默忽略** —— 回一句「你没有权限」等于告诉刷屏的人这条命令存在、
值得去试。

`/ban` 的标记结果进正例池，是质量最高的训练样本，形态摘要下一轮就能学到。

## 通知

- **群内展示**（每群开关，默认关）：逐条贴处置结果与按钮，按人节流，
  到点自动撤回（撤回记在库里，重启不丢）。不带昵称与原文。
- **私聊汇总**（默认开）：命中、判定失败、复判为正常汇成一条，每隔
  「私聊汇总间隔」（默认 5 分钟）最多一条。点「📋 #编号」进记录卡片处置。

记录卡片上可以一键「↩️ 误判」—— 样本进反例池参与闭环学习，详见
[判定链路](how-it-works.md#闭环学习)。
